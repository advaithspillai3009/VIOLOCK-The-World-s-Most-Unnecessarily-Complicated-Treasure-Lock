VIOLOCK CUTSCENE VIDEOS DIRECTORY
=================================

Place your video files here:
1. intro.mp4  - Cinematic Intro Video
2. climax.mp4 - Cinematic Climax Video

The filenames can be configured in static/cutsceneManager.js:
const CUTSCENES = {
    intro: "/static/assets/cutscenes/intro.mp4",
    climax: "/static/assets/cutscenes/climax.mp4"
};
